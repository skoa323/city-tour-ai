# city-tour-ai

一个「城市漫游 + AI 居民」的交互原型。不是 GTA6，是一个街区的垂直切片。

现在只有一个人物：涩谷 のんべい横丁「源」的店主 **野村源次**。

## 这个 repo 的核心主张

**拒绝不是模型决定的。**

NPC 拒不拒、赶不赶人，由一份确定性的规则闸门在调用 LLM 之前判定；模型只负责「同一句拒绝，冷 / 平 / 暖三档怎么说」。

- 规则可测试、可复现（同样的输入序列 → 同样的输出）
- 模型换掉、模型超时、模型挂掉，人设不崩
- 好感度能升能降，NPC 记得你干过什么

## 里面有什么

| 文件 | 是什么 |
|---|---|
| `genji.json` | 人物卡：位置、外形、日程、拒绝触发器、好感档位、秘密 |
| `npc_core.py` | 可运行的规则闸门 + 记忆 + 台词库（无依赖，纯 stdlib） |
| `genji.html` | 可视化 Demo，点按钮就能玩，好感条会动 |
| `TASK-001-devin.md` | 交给 Devin 的第一个任务 spec（可直接当 issue 用） |
| `ARCH.md` | 架构草案：World Server / Cognition / Director / LLM Gateway |

## 跑起来

```bash
python3 npc_core.py --demo     # 一个完整的故事：第一次进店 → 问拆迁 → 拍照 → 隔天道歉
python3 npc_core.py --clean    # 对照组：从没拍过照的玩家，三晚爬到 respect 71
python3 npc_core.py            # 自己打字跟他聊（/photo 举手机，/new 第二天，/quit 退出）
```

可视化：用浏览器打开 `genji.html`。

## 拒绝逻辑

| 触发 | 判定 | respect |
|---|---|---|
| 举手机 / 写真・撮る・インスタ | `refuse_photo` | −12 |
| 问拆迁、再开发、收购 | `shut_down` | −14 |
| 点菜单外的东西 | `state_menu` | −3 |
| 一次带 3 人以上 | `refuse` | −6 |
| 连两轮大声 | `eject`，拉黑 7 天 | −100 |

反向通路：道歉 +8、夸店 +5、隔天再来 +4（且从没拍过照再 +4）。
